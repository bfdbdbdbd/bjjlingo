Login com Google

Para ativar o login com Google, cole seu OAuth Client ID no script.js (variavel GOOGLE_CLIENT_ID, no topo do arquivo). Como configurar:

  1. Acesse console.cloud.google.com e crie um projeto.
  2. Em "APIs e servicos" > "Tela de consentimento OAuth", crie um app externo.
  3. Em "Credenciais", crie um Client ID OAuth tipo "Aplicativo Web".
  4. Adicione a origem autorizada: http://localhost:8000.
  5. Copie o Client ID para o script.js e salve.
  6. Abra o app por um servidor local (ex.: python -m http.server 8000) e acesse http://localhost:8000.
